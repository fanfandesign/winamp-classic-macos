# Управление Winamp Classic

Перетащите аудиофайлы в окно или нажмите **ADD / ⌘O**. Двойной щелчок по треку запускает его.

## Клавиатура

| Клавиши | Действие |
| --- | --- |
| Пробел | Воспроизведение / пауза |
| ← / → | Перемотка на 5 секунд |
| Z / X / C / V / B | Предыдущий / воспроизведение / пауза / стоп / следующий |
| Enter | Воспроизвести выбранный трек |
| Delete | Удалить запись из плейлиста; файл остаётся на диске |
| ⌘O | Добавить аудиофайлы |
| ⌘S | Сохранить плейлист M3U8 |
| ⌘E / ⌘L | Показать или скрыть эквалайзер / плейлист |
| ⌘2 | Переключить масштаб 1× / 2× / 3× |

## Кнопки и мышь

- **EQ / PL** — показать или скрыть панели эквалайзера и плейлиста.
- **SHUFFLE / ↻** — случайный порядок / повтор всего плейлиста.
- **REM** — удалить выбранную запись или очистить список.
- **MISC** — сортировка и масштаб.
- **LIST** — загрузить или сохранить плейлист; **SEL** — перейти к играющему треку.
- **ON** — включить обработку эквалайзером.
- **AUTO** — сохранять и восстанавливать настройки EQ для каждого трека.
- **PRESETS** — выбрать Flat, Bass boost или Rock.
- Щелчок по времени переключает прошедшее и оставшееся время.
- Окно перемещается за заголовок любой панели.
- Правый щелчок открывает меню основных действий; в меню доступны стрелки, Enter и Escape.
